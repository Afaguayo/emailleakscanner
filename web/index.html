Email Leak Scanner

Checks XposedOrNot, LeakCheck, HaveIBeenPwned (with a key) and the public web. Only scan addresses you own.

Has a password leaked?

Your password never leaves this computer. It is hashed with SHA-1 and only the first 5 characters of the hash are sent to Pwned Passwords, which returns every leaked hash starting with them; the match happens here.

HaveIBeenPwned API key

Optional. HIBP charges for API keys (haveibeenpwned.com/API/Key). The key is stored in .emailleakscanner.json in your home folder. XposedOrNot and LeakCheck work without any key.
